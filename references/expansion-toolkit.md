# 擴寫工具箱（expansion-toolkit）

本檔提供 wenyan-story-extender 各階段的具體操作素材。

## 1. 六何法問題庫（階段 2 規劃與階段 3 擴充細節用）

遇到「不知道這段寫什麼」時，從以下問題挑 2–4 個來問，答案就是內容：

| 六何 | 問題 |
|---|---|
| 何人 | 他是誰？什麼身分／年紀／脾氣？和誰一起？關係如何？旁人怎麼看他？ |
| 何事 | 具體做了什麼？過程分幾步？先發生什麼、後發生什麼？有什麼阻礙？ |
| 何地 | 在哪裡？那個地方長什麼樣（光線、氣味、聲音）？環境對當事人意味著什麼？ |
| 何時 | 什麼時候？清晨／深夜／節令？時間壓力？（來不及了？等很久了？） |
| 為何 | 為什麼要做？動機、苦衷、執念？如果不做會怎樣？ |
| 如何 | 怎麼做的？動作細節？神情？說的話？心裡的糾結？ |

擴充細節的順序建議：先「何事＋如何」把事件寫實，再「何人＋為何」把人物寫深，最後「何地＋何時」把場景寫活。

## 2. 擴寫五要訣檢查表（每段生成後對照）

- [ ] 聯想觸發：這一段有沒有從原文某個字詞出發的合理聯想？
- [ ] 詳細陳述／反覆論辯：關鍵情節有沒有寫夠細節？值得強調的點有沒有多角度鋪陳？
- [ ] 補充省略：原文省略的主語、受詞、因果，是否已補回並寫明？
- [ ] 抽象變具體：有沒有抽象形容詞（辛苦／悲傷／熱鬧）沒轉成具體畫面？
- [ ] 隱晦變具體顯示：原文暗示的情感，有沒有用行動／細節「演」出來，而不是「說」出來？

## 3. 起承轉合模板（含情感弧線）

```
起：場景切入 —— 先讓讀者看見一個畫面或一個人（情感起點：平靜／好奇）
承：事件展開 —— 按時間推進，細節堆疊（情感漸進：投入）
轉：轉折或頓悟 —— 衝突、反差、恍然大悟（情感高峰或低谷）
合：收束餘韻 —— 回到原句意旨，最後一句留味道（情感落點：釋然／感嘆）
```

情感弧線四種基本形狀：
- 平靜 → 漸深 → 波動 → 釋然（溫暖型）
- 輕快 → 熱鬧 → 急轉 → 蒼涼（反差型）
- 疑惑 → 追索 → 明朗 → 感慨（領悟型）
- 壓抑 → 爆發 → 沉澱 → 平靜（釋放型）

## 4. 情感基調字典（階段 0 選項 → 敘事提示）

| 基調 | 敘事提示 |
|---|---|
| 溫暖 | 多寫人與人的善意細節；語氣和緩；結尾給一點希望 |
| 哀愁 | 多用慢節奏、留白；景物渲染（雨、黃昏）；少說破、多暗示 |
| 激昂 | 短句、排比、動作感強；語氣上揚；可加適度對話呼喊 |
| 詼諧 | 生活化比喻、自嘲、意外轉折；節制，不喧賓奪主 |
| 蒼涼 | 時間感強（季節流轉、物是人非）；克制的情感；結尾簡短有力 |
| 懷舊 | 大量感官記憶（氣味、聲音）；「那時候」句式；溫和感嘆 |
| 平淡自然（預設） | 不刻意煽情；細節真實；情感藏在動作裡 |

## 5. 口語化對照表

| 書面腔（避免） | 口語化（使用） |
|---|---|
| 他感到十分悲傷 | 他心裡堵得慌 |
| 這是一段艱難的歲月 | 那段日子，真不好過 |
| 她注視著遠方 | 她盯著遠處發愣 |
| 眾人皆驚 | 大家都愣住了 |
| 旋即 | 馬上／轉眼 |
| 遂／乃 | 於是／就 |

規則：**先寫白話，再讀一遍**。讀起來像「唸稿」的地方，改成像「講話」。

## 6. 常見錯誤（校驗時對照）

1. **擴寫變改寫**：改了主旨、結局或體裁（如把敘事改成了議論）→ 回去對原文。
2. **擴寫變續寫**：在原文結尾之後繼續編情節 → 原文的結局就是文章的結局，後面只能收束。
3. **人稱漂移**：前面「我」後面變「他」→ 統一。
4. **情感浮誇**：每句都感嘆、每段都催淚 → 情感要有「留白」，平淡處才顯得出高潮。
5. **現代詞亂入**：文言時代背景的人物說「躺平」「內卷」→ 節制或避免。
6. **字數灌水**：重複敘述、繞圈 → 刪掉重複，改用新細節擴充。
7. **金句遺失**：原文最精彩的字句沒出現 → 必須保留或化用。

## 7. 標點符號運用指南

文言原文沒有標點，擴寫成口語敘事時，標點負責**節奏與情緒**：

| 標點 | 用途 | 範例 |
|---|---|---|
| 。 | 斷句、控制節奏（短句密集＝急促／緊張） | 他沒說話。只是把書又翻過一頁。 |
| ， | 句內停頓、並列、鋪陳 | 風從門縫裡鑽進來，在屋裡轉一圈。 |
| 、 | 列舉（同類並列） | 春秋的風、盛唐的月、古人的憂愁。 |
| ； | 對照、分句之間的層次 | 書是別人的；抄下來，字就是自己的了。 |
| …… | 留白、哽咽、思緒未盡、話沒說完 | 他張了張嘴，想說些什麼，最後只輕輕搖了搖手…… |
| —— | 停頓、轉折、補充解釋 | 那間屋子是真的空——牆是土的，地是土的。 |
| ？ | 疑問、自問、反問（加強情緒） | 有人問他，晚上還讀什麼書？ |
| ！ | 驚嘆；**克制**，一篇一兩處 | 原來那盞燈，從來就沒滅過！ |
| 「」 | 對話、金句、心理獨白 | 他低聲說：「謝了。」 |
| 《》 | 書名、篇名 | 他把《論語》抄了三遍。 |

規則：

1. **標點是節奏器，不是情緒貼紙**——先寫出情緒，再讓標點幫節奏；情緒要靠細節，不靠標點數量。
2. **禁止**：感嘆號連用（！！／！！！）、問號連用（？？）、省略號刷屏（每句都……）、破折號濫用、一逗到底。
3. **對話標點在引號內**：「我明天回來。」不是「我明天回來」。
4. **金句嵌入**：原文金句用引號「……」保留原味，或用破折號引出再化開。
5. **基調決定標點密度**：蒼涼/哀愁 → 多句號與省略號、少感嘆號；激昂 → 短句＋句號密集、一兩處感嘆號收束。
